# Hold The Line - download

Official site and download of **Hold The Line**, a WWII machine-gun defence shooter for Windows:
https://boaz71.github.io/hold-the-line-download/

Get the game from the [latest release](https://github.com/boaz71/hold-the-line-download/releases/latest):
`HoldTheLine.zip` - unzip it and run `HoldTheLine.exe`. The release notes list the zip's SHA-256.

This repository holds only the site and the release files, not the game's source.
